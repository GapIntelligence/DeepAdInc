# Deep.ad — part of OpenBrand

Deep.ad combined with Gap Intelligence in 2023 to form OpenBrand. Its AI-powered data collection and advertising intelligence are part of OpenBrand's market intelligence offering.

This repository introduces the Deep.ad business; it is not a software SDK or a product support portal.

## Technology background

Deep.ad's work includes identifying brands, products, and advertising in digital media using computer vision, optical character recognition (OCR), and brand recognition across images, video, and web content.
